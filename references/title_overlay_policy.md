# Title overlay policy

This policy applies to every theme and overrides legacy prompt examples.

Generate text-free artwork. Reserve the title zone as native visual material, not a floating panel.
Never ask the image model to render Chinese titles, subtitles, citations, labels, numbers, or brand names.

For every final or prompt-only package, provide:

- exact main title and subtitle;
- title-zone x/y/width/height as canvas proportions;
- alignment, type mood, type palette, and integration device;
- a one-line instruction that the image tool must keep the zone empty, low-detail, and free of focal objects.

For mechanism or infographic themes, provide any labels and data values as a separate post-production
text list. Do not ask the image model to render them.
