# 主题四：粘土/泥塑立体微缩风（Clay Diorama / Polymer Clay）

## 1. 风格定位

| 维度 | 设定 |
| --- | --- |
| **视觉调性** | 温暖治愈、亲切可爱、零距离感；适合"讲人话"的科普向内容 |
| **画幅比例** | **21:9 横版（1260 × 540px，≈ 微信 2.35:1）**，与其他主题一致 |
| **核心工艺** | 手工捏制的 polymer clay / plasticine 软陶感，柔光摄影棚打光 |
| **常见场景** | 多步骤方法论 / 工作流指南 / 系统初始化教程 / 框架五要素 / 平台搭建综述 / 标准化 SOP 概述 |
| **不适配场景** | 单点深机制（用主题一）、震撼大发现（用主题三）、信息密度高的小数据图（用主题一） |
| **情绪标签** | 治愈、亲近、靠谱、低压迫感、像在听朋友讲 |
| **与读者距离** | "像在一张温暖桌布上，给你展示五件可爱道具" |

> 领域无限制：多步骤流程无论「mRNA 加帽工艺三步路线」还是「AI 智能体初始化五步」「平台搭建四要素」都适用。

## 2. 视觉构造规范

### 2.1 画布与背景
- **画布**：1260 × 540px 横版，21:9
- **主背景**：暖米色 `#F5E6C8`（peach-beige），覆盖全幅
- **远景层次**：水平地面线把画面切成上 40% 天空 + 下 60% 地面景观
- **远山/丘陵**：用 3-4 个低饱和度的弧形剪影叠加，色彩从 `#E8D5B7` 到 `#D9C09C` 渐淡
- **地面纹理**：浅亚光纹理（不是磨砂硬纸，是软陶的"指纹痕迹"），roughness 中等

### 2.2 装饰元素（推荐出现，但不抢戏）
- **圆顶树**：3-5 棵，圆球树冠（`#95CFA7` 薄荷绿），棕色树干（`#8C6B4F`），可有红色/橙色"果子"
- **蓬松云朵**：2-3 朵，白色立体堆叠云，带轻微阴影
- **圆台底座**：3-5 个，扁圆形 cake-stand，每个直径 130-180px，高度 30-45px，颜色对应所属模块主色
- **散落小物件**：圆润石头、彩蛋、简单几何块（小圆锥、小拱门）作为视觉节奏补点
- **小标签牌（pill tag）**：圆角矩形糖果色牌，挂在对应模块上方或近旁

### 2.3 模块布局（核心）
- **每个模块 =「圆台底座 + 上立立体角色/物品」**，横向一字排开
- 模块数量：**3-5 个**（少于 3 浪费画面，多于 5 拥挤）
- 模块间留 **80-110px** 间距
- 模块垂直位置略错落（±10-15px），避免死板
- 模块对应配色从色板里**循环取**，相邻模块不同色系

### 2.4 色板（Clay 10 色）
| 用途 | 色名 | 色值 |
| --- | --- | --- |
| 背景主色 | 奶油米 | `#F5E6C8` |
| 远景丘陵 | 浅驼 | `#E8D5B7` |
| 模块·蓝 | 天蓝 | `#8FB8D6` |
| 模块·绿 | 薄荷绿 | `#95CFA7` |
| 模块·粉 | 樱花粉 | `#E89BAA` |
| 模块·橘 | 暖橘 | `#E89F5C` |
| 模块·红 | 绛红 | `#C76B5C` |
| 模块·紫 | 薰衣紫 | `#A38BBA` |
| 模块·黄 | 鹅黄 | `#F0CC58` |
| 文字深色 | 棕褐 | `#2B1810` |
| 说明文字 | 中棕 | `#5A4030` |

### 2.5 字体与排版
- **总标题**：卡通手写感（Ma Shan Zheng / 站酷快乐体），36-42px，粗黑，色 `#2B1810`，居中或贴顶 banner
- **副标题**：Noto Sans SC / 黑体，14-16px，色 `#5A4030`，单行居中
- **模块小标签**：Noto Sans SC Bold，16-20px，白字 + 深色描边 1px，贴圆角矩形糖果底色
- **模块配文**：Noto Sans SC Regular，13-15px，色 `#2B1810`，**字数 ≤ 32 字**，可两行换行

### 2.6 灯光与材质
- **主光**：左上 45° 柔和柔光箱，强度 70-80%
- **辅光**：右前 30°，强度 25-30%，避免纯黑阴影
- **环境光**：整体提亮，soft ambient 20%
- **阴影**：接触阴影（contact shadow）柔化、半径 15-20px、透明度 25-35%
- **材质**：磨砂 polymer clay、轻微指纹感、无金属反光、无玻璃透光
- **画风约束**：**禁止 3D 写实 / 金属 / 玻璃 / 强反光 / 等距光刻**

### 2.7 文本与平台回退

- 总标题可以要求 `Chinese hand-brushed text exactly: "..."`，但应控制长度并放入安全区。
- 模块标签和配文是小字：标签尽量 4–6 个汉字，配文尽量改为英文/数字或后期叠加。
- 需要精确显示的模块文字应预留 quiet zone，由宿主的排版/图像编辑能力后期添加；没有后期能力时交付视觉草稿和独立文字清单。
- 本主题的右下角不再要求生成“水印”。品牌名应视为可选后期 overlay；平台强制水印无法依靠 negative prompt 删除。

## 3. 填入内容 schema

调用本主题前，先在文章里识别并列模块。每个模块对应以下三项：

| 占位符 | 含义与长度规则 | 示例（生物医药） | 示例（AI/科技） |
| --- | --- | --- | --- |
| `{title}` | 文章主标题，≤30字 | `mRNA 体外转录加帽法的三步路线` | `AI 智能体初始化五步走` |
| `{subtitle}` | 一行说明，≤50字 | `从共转录到酶法后加帽的工艺取舍` | `从环境检查到首个任务执行的路径` |
| `{step_count}` | 阿拉伯数字 3–5 | `3` | `5` |
| `{step_label_1}` | 短标签，优先 4–6 字 | `共转录加帽` | `环境检查` |
| `{step_visual_1}` | 1–2句拟物造型 | `蓝色圆台上立一根 RNA 试管` | `云服务器小机器人` |
| `{step_caption_1}` | 短配文，建议后期叠加 | `一步加帽` | `确认依赖` |
| `{brand_label}` | 可选品牌名，优先后期 overlay | `信使引擎` | — |
| `{background_accents}` | 可选远景装饰关键词 | `圆顶树、白云、浅驼丘陵` | 同左 |

## 4. Prompt 模板（21:9 横版，英文可直接喂 DALL-E / Midjourney / Gemini）

```
A horizontal banner image at 21:9 aspect ratio (1260x540px), clay diorama / polymer clay style on warm peach-beige paper (#F5E6C8 background), soft diffuse studio lighting from upper-left, no metallic reflections, slight fingerprint texture on every object.

BACKGROUND & SCENE: A continuous shallow ground plane in muted tan (#D9C09C) runs across the lower 60% of the canvas. Behind it, 3-4 softly rounded hill silhouettes in pale beige (#E8D5B7) fade into the warm sky. Two-three fluffy white polymer-clay clouds float in the upper-left sky. 3-5 cute rounded-crown trees (mint green #95CFA7 canopies, brown #8C6B4F trunks) are scattered between and behind the modules as gentle visual rhythm. ## 5. 调用流程
```

1. 当用户选定方案适合"多步骤流程 / 多模块拆解 / Setup 指南"型内容时，主 Agent 推荐主题四
2. 从文章中提取 `{step_1..N}` 三元组（短标签 / 图标描述 / 配文），若多于 5 个则合并或取舍到 5
3. 从 `{module_N_color}` 指定每模块底色（不强求，默认循环取色板）
4. 输出完整 prompt，**保留全部 `{}` 被替换后的最终英文**，确保可直接喂 DALL-E/Midjourney/Gemini
5. 在 prompt 末尾附中文 **「创作说明」** 段（200 字内），告诉用户：
   - 风格是什么
   - 哪些 `{}` 是必填、哪些可选
   - 如果生成结果风格偏移，可补哪几个反向关键词

## 6. 失败回退

| 现象 | 处理 |
| --- | --- |
| 生成结果风格偏扁平矢量/扁平卡通 | 在 prompt 内追加 `no flat vector, no flat 2D, must be 3D clay sculptural` 并重新生成 |
| 生成结果偏写实、材质变金属 | 在 prompt 内追加 `must retain hand-crafted polymer clay texture, no PBR realism` |
| 生成结果跑题变成信息图 | 删除 `MODULE CONTENTS` 段落里的坐标/百分比描述，只留视觉造型 |
| 模块数 > 5 | 合并为 5 模块，其余作为配文里的"延伸要点"补充 |
| 中文小标签识别错乱 | 在 label 字符串前后加双引号包裹，并在 prompt 前置 `Chinese text labels exactly: "{步骤X小标签}"` |

## 7. 典型适用与不适用

✅ **适用**：如何 3 分钟初始化 WorkBuddy、加帽工艺三种路线、五要素评估框架、四步 SOP 拆解、靶向 LNP 五种偶联方式概览、CDMO 选址打分体系；AI/科技示例——AI 智能体初始化五步、模型训练流水线四阶段、云平台搭建四要素、数据管线 Setup 指南

❌ **不适用**：单点深机制（用主题一）、数据型大发现（用主题三）、重磅新闻事件（用主题三）、单模块单图（用主题二）
