# Security Policy

## Reporting a vulnerability

Please do not open a public issue containing vulnerability details. Use GitHub's private vulnerability reporting form at `https://github.com/rcrusoe88-bot/wechat-cover-design/security/advisories/new` with a description, impact, and steps to reproduce. If the form is unavailable, open a minimal public issue asking the maintainer to establish a private contact channel; do not include sensitive details.

We will acknowledge valid reports and coordinate a fix before public disclosure when practical.

## Scope

Do not include API keys, credentials, personal information, or sensitive business data in bug reports, issues, pull requests, or examples.
